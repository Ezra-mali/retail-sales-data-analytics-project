# Data Dictionary

Dataset Source: Kaggle Superstore Retail Dataset

## Column Description

| Column Name | Description | Data Type | Notes |
|-------------|-------------|-------------|------|
| Row ID | Unique transaction identifier | Integer | Primary key |
| Order ID | Transaction order code | String | Groups items in same order |
| Sales | Revenue generated | Float | Key business metric |
| Profit | Business profit | Float | Can be negative |
